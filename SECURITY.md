# Security policy

Do not report suspected vulnerabilities, compromised packages, signing-key
concerns, or private environment details in a public issue or discussion.

Use this repository's private vulnerability reporting form:

<https://github.com/AmjedAllaya/automexia-releases/security/advisories/new>

Include the release tag, filename, SHA-256 digest, operating system, CPU
architecture, and the smallest safe reproduction. Remove usernames, paths,
hostnames, credentials, terminal history, and organization data before sending
evidence.

For an integrity concern, stop using the affected package until Automexia has
published an advisory or a new version. A released asset will not be silently
replaced.
