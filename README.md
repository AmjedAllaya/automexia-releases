## Your command line, with room to work

Keep shells side by side with split panes and tabs. Find text in one pane or
across visible panes. Adjust font size and appearance, and keep those preferences
between launches. Use the command palette to discover available actions.

This is the official **binary-only release archive**. It contains public user
guides and branding; the application packages are attached to GitHub Releases.
No account is required to download them.

## Download Linux v0.4.0

Choose **one** package for your distribution and CPU. Run `uname -m` if unsure:
`x86_64` means x64; `aarch64` means Arm64. These are GNU/Linux builds, not musl
builds. Read the [requirements and evidence limits](INSTALL.md#requirements)
before installing, and [verify your download](VERIFY.md) before running it.

## Trust and transparency

Each release includes signed SHA-256 checksums, a public Minisign key, SPDX and
CycloneDX dependency inventories, release notes, installation/removal guidance,
third-party notices and a public distribution manifest. Published package assets
are immutable: a correction requires a new version, not a replaced download.
