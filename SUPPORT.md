# Support policy

This repository is a passive, binary-only release archive. It does not accept
issues, feature requests, source-code support requests, or unsolicited pull
requests. Maintainers use reviewed pull requests only for archive policy and
metadata changes.

For installation, removal, checksum, and signature guidance, use the documents
attached to the exact release and the public documentation at
<https://www.automexia.com/docs>. Only files listed in `SHA256SUMS` and the
source-commit-bound public distribution manifest are supported application
artifacts. GitHub's automatically generated source archives are not Automexia
Terminal packages.

Report suspected vulnerabilities or release-integrity concerns through the
private route in [SECURITY.md](SECURITY.md). Do not post credentials, private
terminal output, usernames, hostnames, local paths, account identifiers, or
organization data in any public channel. For a safe diagnostic, include only
the release tag, package filename, SHA-256 digest, operating system, CPU
architecture, and a redacted minimal reproduction.
